# Gait Classification Using HuGaDB

## Overview

This project explores the HuGaDB (Human Gait Database) dataset for Human Activity Recognition and gait analysis.

## Dataset Information

The dataset contains:

- Accelerometer data
- Gyroscope data
- EMG signals

Sensor locations:

- Right Foot
- Right Shin
- Right Thigh
- Left Foot
- Left Shin
- Left Thigh
